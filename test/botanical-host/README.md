# rc.5 optional botanical isolation host regression

Use only disposable hosts with synthetic fixtures; never run against a personal DSH home. The host logs and raw browser traces contain temporary tokens; do not publish them. The results JSON files here were generated without model or tool execution and are sanitized.

Create separate marked disposable roots for ordinary, stock Claude Style 0.19.1, and controlled stream tests. Within each root create `home`, install the exact packed plugin under that `DSH_HOME`, and start rc.5 on a loopback port. For the first two, load `test/fixtures/cordis.patch.yml`; for stream, set `DSH_STREAM_TEST_DIR` to the root and load `test/fixtures/stream-fixture.patch.yml`. Each must contain `.dpt-disposable-test`. Run the existing `npm run test:host` in the first two with `DSH_TEST_PROFILE_PATCH`, `DSH_EXPECT_FILTERED_REASONING=1` and, for theme, `DSH_EXPECT_THEME=1`.

For optional-mode tests, supply `DPT_HOST_TEST_ROOT`, `DSH_HOME` and `DSH_TEST_HOST_LOG` within that root, set `DSH_EXPECT_THEME=1` for theme, and run `node host-optin.cjs`. It explicitly changes and restores the disposable profile patch to test real live disable/re-enable. This checks default-off, real UI enabling, matching per-row anchors and centers, layout, themes, fold, reload, disable/re-enable, and restoration of regular DOM. For streaming, set `DSH_STREAM_TEST_DIR` and `DSH_TEST_HOST_LOG` and run `node host-stream-optin.cjs` in a fresh disposable stream root. Both scripts need Playwright accessible, e.g. via `NODE_PATH` pointing to the project node_modules. Stop the servers at the end.

One early theme check failed because it clicked collapse and expand without waiting for the host's asynchronous aria-expanded state. The original failing result is preserved as `docs/verification/rc5-botanical-regression.json` under `firstThemeFailure`. The final test waits for each actual state and shadow reattachment, then still checks each visible anchor and node center; it passed twice in a fresh theme profile. The synthetic fixture was inspected after fold/restore.
